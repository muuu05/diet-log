    데이터와 AI

    백업

    기록은 이 휴대폰에만 있어요. 일주일에 한 번쯤 백업 파일을 내보내서 파일 앱이나 클라우드에 보관하세요. 새 휴대폰에서는 ‘백업 가져오기’로 그대로 옮길 수 있어요.

    사진 읽기 (선택)

    식사 사진 칼로리 추정과 인바디 결과지·NRC 캡처 읽기는 내 Anthropic API 키로 Claude를 불러서 해요. Claude 구독과는 별개로 Claude Console에서 쓴 만큼 요금이 나가요. 키는 이 휴대폰에만 저장되고, 사진을 읽을 때만 Anthropic으로 보내져요.

    키는 Claude Console에서 만들어요. 이 앱 전용 키를 따로 만들고, Console의 결제 설정에서 월 사용 한도를 걸어 두면 안심이에요.

    기록은 이 휴대폰 안에만 저장되고 어떤 서버로도 보내지 않아요. 사진 읽기를 쓸 때만 그 사진이 내 API 키로 Anthropic에 보내져요. 휴대폰을 바꾸거나 홈 화면에서 앱을 지우면 기록이 사라질 수 있으니 ‘데이터와 AI’에서 가끔 백업을 내보내 두세요.
